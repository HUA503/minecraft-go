# 兼容性与差距清单

本表记录代码中能确认的实现范围。**“有实现”不表示与原版等价，也不表示已通过原版客户端/服务端互操作验证。** 目前没有完整的 Minecraft Java Edition 或 Horizon 兼容性。

| 部分 | 当前可确认的实现 | 主要差距 / 状态 |
|---|---|---|
| 网络协议 | 自定义握手、部分状态流、若干基础包、VarInt 编解码 | 包集合、字段、版本协商、压缩/加密、登录配置及原版互通均未完整验证；不能声称原版兼容 |
| 世界存档 | MCA 区域文件读写、区块和部分 level/player 数据 | 原版 NBT 字段、实体/方块实体、维度、数据版本升级和异常恢复覆盖不完整 |
| 世界生成 | Go 程序化生成主世界、下界和末地的部分地形 | 生物群系、结构、矿物分布、地形噪声、维度细节与原版差异较大 |
| 方块与物品 | 部分方块、物品、工具、掉落和配方 | 全量注册表、方块状态、属性、交互、配方和资源映射未完成 |
| 模拟与实体 | 基础玩家移动、碰撞、物品掉落和少量生物行为 | AI、寻路、战斗、实体种类、生成条件、状态效果、红石/流体细节未达到原版行为 |
| 渲染 | 自制软件光栅器、区块网格、HUD 和若干程序化材质 | 不是原版图形管线；贴图、光照、透明度、阴影、动画、性能和 UI 均有明显差异 |
| 进度系统 | 少量本地进度触发和界面；故事线的石器时代、获取木头、装配升级和铁镐进度按获得对应物品触发 | 未实现原版完整条件树、奖励、同步与数据格式；其余触发覆盖不足 |
| 服务端与生态 | Go 服务端、基础连接和有限广播 | 插件/模组 API、管理工具、命令/权限、代理兼容、性能扩展及真实互操作测试缺失 |
| 平台 | Go 核心可构建；客户端窗口采用 Win32 | 原生图形客户端目前限 Windows；Linux/macOS 窗口端未完成 |

## UI 还原进度

- 已将玩家物品栏/2×2 合成、工作台和熔炉窗口的面板底图替换为 Mojang 26.3 客户端原始纹理，并按原版 176×166 GUI 区域绘制。
- 修正玩家物品栏 2×2 合成格、输出格、盔甲槽和副手槽的位置及点击命中；加入盔甲/副手直接操作和基础 Shift 点击装备。熔炉进度和燃烧图标也使用 26.3 官方精灵图。
- 创造栏条目中的方块图标按等距方块模型绘制；非方块物品优先使用 Mojang 原始精灵图。当前目录的非方块物品图标已加回归检查，缺少官方图标时测试会失败。
- 玩家预览仍是项目内的简化软件模型；这只是容器界面的一部分，原版字体、完整交互/动画、其他容器屏幕和图形管线仍有明显差距，不能称为原版 UI。

## 进度触发核对

- “石器时代”在获得圆石时触发，而不是仅挖掘石头时触发；“获取木头”在获得原木、木头、菌柄等日志物品时触发。
- “装配升级”只在获得石镐时触发；“不再是木镐”只在获得铁镐时触发。拾取与合成获得都会经过同一物品判定。
- 其他进度目前仍只有部分触发；进度树、前置条件、展示图标、奖励与 Java 存档格式没有完整对齐。

## 创造物品目录差距（代码核对）

`CreativeCatalog(CreativeAll)` 当前返回 850 条。对照 Mojang 26.3 客户端资源，项目本批补入了 16 种独立染料及官方图标。仓库内 `vanillaCreativeTabOrder` 现在有 1,424 个分类条目；其中 565 条没有本地映射，23 条在 `assets/minecraft/items/*.json` 中没有独立物品模型（如分类汇总名），另有 542 条虽有官方模型但项目缺少映射。分类表会重复列出跨类别物品，因此这里统计的是 tab 条目数，不是唯一物品总数。

| 分类 | 目标顺序表条目 | 对应官方模型存在但缺少本地映射 |
|---|---:|---:|
| 建筑方块 | 387 | 76 |
| 装饰方块 | 101 | 4 |
| 自然方块 | 254 | 121 |
| 功能方块 | 134 | 111 |
| 红石方块 | 136 | 1 |
| 工具与实用物品 | 67 | 47 |
| 战斗 | 118 | 72 |
| 食物与饮料 | 78 | 28 |
| 材料 | 60 | 3 |
| 刷怪蛋 | 89 | 79 |

该核对只证明当前代码的映射缺口；本地项目尚未实现这些条目的完整注册、贴图、堆叠规则和游戏行为，不能据此宣称物品数量或功能达到原版。

染料行为目前支持 15 种染料与白色羊毛的无序合成，产出对应颜色羊毛；对白色羊毛使用白色染料没有改变物品，因此不注册该配方。给羊、盔甲、玻璃、陶瓦等染色，以及染料参与的其他配方仍未实现。

当前活珊瑚块可放置为完整方块，挖掘时按 26.3 掉落对应的死亡珊瑚块；死亡珊瑚块掉落自身。随机刻会检查相邻水和空气：有水时保持存活；无水且接触空气/虚空时变为对应死亡珊瑚；完全由实心方块包围时保持存活。水浸方块状态尚未实现，因此暂不识别相邻的水浸方块；丝触保留活珊瑚及爆炸掉落衰减也未实现。

已加入三种蛙明灯的完整方块模型纹理和基础自掉落；方块光照发射与光照传播尚未实现，因此它们不会像原版一样照亮周围环境。

## 近期稳定性改动

- 客户端模拟已串行到渲染主线程，减少本地 Tick 与绘制共享状态的竞争。
- 退出时关闭客户端网络读取并等待其结束；窗口和 CLI 退出会走存档收尾。
- 服务端等待连接会话退出后再保存，关闭各维度的区域文件。
- 网络帧大小限制为 2 MiB，防止异常长度触发大额内存分配。
- 保存并恢复昼夜时钟。

这些改动尚未由 `-race` 或完整真实游玩回归验证。当前环境缺少 CGO 编译器，race detector 尚不可用；用户报告的实际闪退也还没有在此环境复现。
